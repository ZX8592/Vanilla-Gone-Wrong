# 原版失控 · Vanilla Gone Wrong

**让熟悉的原版生存，变得不一样一点！**

当熟悉的原版生存逐渐变得单调，也许你需要的只是一些意想不到的变化。原版失控以 Minecraft Java 版的原版内容为框架，通过 200 多项设定修改，重新组合、延伸和加强熟悉的方块、生物与物品，让整个生存流程充满意外。所有内容都围绕原版展开，保持统一的风格；熟悉原版的玩家可以直接上手，借助进度引导在游玩中理解新规则，几乎没有额外的学习成本。设计之初便兼顾趣味性、挑战与可玩性，虽然难度较高，玩家仍能通过观察、准备和应变完成通关。设计思路和部分机制借鉴了老版本 Insane Difficulty（猛男生存）数据包，希望带回那种混乱、有趣、总有惊喜的生存体验。

## 安装

1. 下载并解压源码，将同时包含 `pack.mcmeta` 和 `data/` 的整个目录放入目标世界的 `datapacks/` 文件夹。也可按下方步骤手动打包，将生成的安装 ZIP 放入 `datapacks/`，无需解压。
2. 进入世界，或在已有世界中执行 `/reload`。服务端也可以重新启动加载。


数据包为 Java 26.3 新世界设计，主要机制面向生存／冒险模式。

已有同版本世界升级时，先退出游戏或关闭服务端、备份整个世界，再替换旧数据包。一个世界只保留一份原版失控，避免不同版本同时运行。

## 玩法一览

- **原版框架，直接上手**：变化来自熟悉的生物、物品和原版机制，内容彼此衔接，原有的生存经验依然有用。
- **重新规划生存**：方块掉落限制、精准采集的新用途、肉类腐坏与护甲重量，让采集、储存和装备选择都有新的取舍。
- **不再安稳的地形**：挖矿可能塌顶，生物会改变脚下地面，爆炸会掀飞方块；洞穴、道路和掩体都需要重新考虑。
- **混乱而有趣的生态**：矿石伏兵、陷阱动物、特殊乘骑和钓鱼异变，让挖矿、赶路甚至收竿都可能带来意外。
- **值得准备的满月**：强化个体、幻翼、空降巨人和传送门怪物波次，让熟悉的夜晚变成一场充满变数的冒险。
- **贯穿后期的维度挑战**：下界的方块受热与菌材药效、末地的特殊乘骑与刷怪笼，让进入新维度意味着面对新的生存规则。
- **全面加强的末影龙战**：龙息弹、俯冲、龙背水晶和地形交互丰富战斗过程，移动、应变与利用机制都能成为战胜巨龙的关键。
- **原版式进度引导**：记录经历、庆祝成果，并提示部分难以推断的规则，让你在探索中逐步理解这个世界。
- **高难度，依然能够通关**：挑战围绕趣味性与可玩性设计，鼓励观察规则、准备装备和寻找对策，完整的生存通关始终是目标。

想保留初见体验，可以先不阅读完整清单。需要了解具体效果时，查看 [数据包效果清单](数据包效果清单.txt)。

## 仓库结构

```text
Vanilla-Gone-Wrong/
├── pack.mcmeta          # 数据包元信息
├── data/                # 当前版本完整游戏资源
├── 数据包效果清单.txt   # 当前效果清单，也是安装包内唯一的说明文档
└── README.md
```

根目录本身也是一个数据包目录，可以复制到世界的 `datapacks/` 下进行本地开发。
