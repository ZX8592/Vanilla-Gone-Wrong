# 原版失控 · Vanilla Gone Wrong

**“让熟悉的 Minecraft 生存规则变得疯狂。”**

## 数据包介绍

当原版生存的节奏烂熟于心、毕业流程变得千篇一律，也许是时候让世界失去控制了。

《原版失控》在纯粹的 Minecraft 原版框架下，通过**200 余项底层机制的深度重构与延伸**，全面激活了你所熟悉的方块、生物与道具生态。这里没有任何突兀的模组化外来机制，却处处颠覆你的记忆。

本数据包在设计思路上借鉴了老版本 Insane Difficulty（猛男生存）数据包，旨在新版本重现那种混乱而有趣的生存体验。

## 安装

1. 下载并解压源码，将同时包含 `pack.mcmeta` 和 `data/` 的整个目录放入目标世界的 `datapacks/` 文件夹。也可按下方步骤手动打包，将生成的安装 ZIP 放入 `datapacks/`，无需解压。
2. 进入世界，或在已有世界中执行 `/reload`。服务端也可以重新启动加载。


数据包为 Java 26.3 新世界设计，主要机制面向生存／冒险模式。

已有同版本世界升级时，先退出游戏或关闭服务端、备份整个世界，再替换旧数据包。一个世界只保留一份原版失控，避免不同版本同时运行。

## 数据包内容

- **资源不再唾手可得**：玩家的资源获取受到了种种限制。概率化的方块掉落，肉类腐败变质，护甲重力等系统的引入将让你不得不重新规划你的生存方式。
- **危机四伏的地形**：加入的全新方块破坏方式将让安稳的方块不再永远稳定。采矿塌方，爆炸掀飞方块等机制将给你的世界带来剧变，生物所过之处甚至会改变脚下的地面。是时候重新考虑你的建筑和掩体了。
- **步步惊心的生态**：数据包在原版世界基础上加入了大量全新事件，危险将随时发生。矿石中暗藏伏兵，动物陷阱，全新的骑乘怪物组合......在这个世界，没有绝对安全的地方。
- **长夜不再安稳**：玩家的睡眠将受到更严苛的限制，熬过漫漫长夜将更加艰难。当心满月的降临，黑夜将化为真正残酷的生存试炼。
- **全面加强的末影龙战**：末影龙战的方式迎来了一场精心设计的重构。新的乘骑组合和地形交互将丰富战斗过程，在巨龙俯冲与地形崩塌中周旋移动吧！应变与利用机制都能成为战胜巨龙的关键。
- **低上手成本**：数据包并没有改变原版的游戏主线框架，你完全可以把它当作原版新的难度游玩。新的进度树将引导你在探索中逐步理解这个世界。
- **硬核但自洽的挑战**：机制的设计充分考虑到了趣味性和可玩性的平衡。不用担心设定过于超标，通过观察规则和寻找对策游玩更为关键。

阅读清单不是游玩前的必要准备，想保留初见体验，可以先不阅读完整清单。需要了解具体效果时，查看 [数据包效果清单](数据包效果清单.txt)。

## 仓库结构

```text
Vanilla-Gone-Wrong/
├── pack.mcmeta          # 数据包元信息
├── data/                # 当前版本完整游戏资源
├── 数据包效果清单.txt   # 当前效果清单，也是安装包内唯一的说明文档
└── README.md
```

根目录本身也是一个数据包目录，可以复制到世界的 `datapacks/` 下进行本地开发。
