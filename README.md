# 原版失控 · Vanilla Gone Wrong

**让熟悉的 Minecraft 生存规则变得陌生。**

原版失控是一个面向 Minecraft Java 版的恶搞高难度数据包。在原版机制上加入夸张、直接的变化：地形不再安稳，生物有了意外的乘骑组合，熟悉的物品和行为也可能产生新的后果。

| Minecraft | **Java 26.3** |

| 作者 | **风ノ夏** |

## 下载与安装

**[下载 v1.44 数据包 ZIP](https://github.com/ZX8592/Vanilla-Gone-Wrong/raw/refs/heads/main/dist/Vanilla-Gone-Wrong_26.3_v1.44.zip)**

1. 将安装 ZIP 放入目标世界的 `datapacks/` 文件夹，无需解压。
2. 进入世界，或在已有世界中执行 `/reload`。服务端也可以重新启动加载。
3. 使用 `/datapack list enabled` 确认启用；进度界面会增加“原版失控”标签页，原版进度仍然保留。

GitHub 的 **Code → Download ZIP** 下载的是整个源码仓库，不能直接当作数据包安装。请使用上面的安装 ZIP，或按下方方法自行打包。

数据包为 Java 26.3 新世界设计，主要机制面向生存／冒险模式。请在游玩过程中及时备份存档；内容量较大，可能出现运行不稳定的情况。

已有同版本世界升级时，先退出游戏或关闭服务端、备份整个世界，再替换旧数据包。一个世界只保留一份原版失控，避免不同版本同时运行。

## 玩法一览

- **生存资源**：普通方块的掉落受到限制，精准采集改变收获规则，随身携带的肉类会腐坏。
- **地形变化**：挖矿可能塌顶，生物会改变脚下地面，爆炸会掀飞部分方块。
- **怪物与生态**：矿石伏兵、陷阱动物、特殊乘骑、持镐掘进等机制改变探索和战斗。
- **满月事件**：强化个体、幻翼、空降巨人和传送门怪物波次让夜晚有不同的威胁。
- **下界与末地**：方块受热、菌材药效、特殊刷怪笼和龙战变化贯穿后期流程。
- **进度系统**：记录经历与成果，并说明部分难以推断的规则。

## 仓库结构

```text
Vanilla-Gone-Wrong/
├── pack.mcmeta          # 数据包元信息
├── data/                # 当前版本完整游戏资源
├── docs/                # 安装说明、效果及进度清单
├── scripts/             # 静态检查与打包脚本
├── dist/                # 可直接安装的当前版本 ZIP
├── README.md
└── CHANGELOG.md
```

根目录本身也是一个数据包目录，可以复制到世界的 `datapacks/` 下进行本地开发。

## 检查与打包

需要 **Python 3.10 或更高版本**，不需要安装第三方库。在仓库根目录运行：

```sh
python scripts/verify.py
python scripts/build.py
```

打包结果写入 `dist/`。安装包包含 `pack.mcmeta`、`data/`、README 和当前使用文档，不包含 Git 元数据、开发脚本、服务端或测试世界。

静态检查会解析资源 JSON、核对本包静态函数引用和文本格式；它不能替代实际游戏测试。当前 v1.44 已进行过无窗口 Java 26.3 服务端的 20 项针对性检查，详见验证说明。
